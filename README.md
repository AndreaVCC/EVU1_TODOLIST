# Mis Tareas

Aplicación móvil de lista de tareas con React Native y Expo SDK 58. Permite agregar, editar, completar, filtrar y eliminar tareas, que quedan guardadas en el dispositivo.

## Ejecutar

```bash
npm install
npm start
```

Escanea el código QR con Expo Go, o usa `npm run web` para abrirla en <http://localhost:8100>.

## Comandos

| Comando | Qué hace |
|---|---|
| `npm start` | Abre el servidor de desarrollo |
| `npm run web` | Abre la app en el navegador, en el puerto 8100 |
| `npm run android` | Abre la app en un emulador Android |
| `npm run typecheck` | Revisa los tipos de TypeScript |
| `npm run lint` | Revisa la calidad del código |
